## 📌 What is Nuke?

Nuke is a **node-based digital compositing application**, originally developed by Digital Domain and now owned by Foundry, used to combine live-action footage, CG elements, and effects into final shots for film, television, and advertising. Its node graph approach — rather than a traditional layer stack — makes it a favorite for complex, high-volume VFX pipelines.

## ✨ Key Features

| Feature                     | Description                                                    |
| ------------------------------- | ---------------------------------------------------------- |
| Node-based Compositing          | Non-destructive, resolution-independent compositing workflow      |
| Keylight & Advanced Keying       | Industry-standard chroma-key and rotoscoping tools                  |
| 3D System (USD-based)             | Integrated 3D scene assembly and camera projection                    |
| CopyCat Machine Learning           | Train custom ML-based compositing tools inside Nuke                    |
| Python & C++ SDK                    | Deep scripting and pipeline integration for VFX studios                  |
| LiveGroups & Collaboration           | Real-time collaborative editing of shared Nuke scripts                     |
| Multi-shot Editorial (Hiero)          | Companion tools for shot management and review workflows                    |
